# API Integration Assignment
This project is about working with different AI APIs using Python.
I created separate programs for each API and tested them using simple prompts.

## APIs used
- OpenAI
- Groq
- Hugging Face
- Google Gemini
- Cohere
- Ollama

## Steps

First install the required packages:
pip install -r requirements.txt

Then set the API keys in terminal:
set OPENAI_API_KEY=your_key
set GROQ_API_KEY=your_key
set HUGGINGFACE_API_KEY=your_key
set GOOGLE_API_KEY=your_key
set COHERE_API_KEY=your_key

Then run any file like:
python openai_api.py

## Files in this project
- openai_api.py
- groq_api.py
- huggingface_api.py
- gemini_api.py
- cohere_api.py
